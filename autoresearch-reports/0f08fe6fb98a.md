**Question.** Goal: improve the exponent of n in the asymptotic upper bound on worst-case head complexity.

Setting. W(n) is the maximum of H*(f) over all Boolean functions f on n bits, in the
one-layer attention model of this repo (Lean: HeadComplexity.worstCaseHeadComplexity and
HeadComplexity.HStar). Do not change the model, the head resource, or the admissibility
conditions on denominators.

Where things stand.
- Upper bound: W(n) = O(2^n/n). See formalization/HeadComplexity/Results/UniversalLinearSaving.lean
  (confirm the exact statements). A separate run proved W(n) <= 2^n/2^floor(log2 n) < 2^(n+1)/n
  in Lean via total dominating sets of the hypercube
  (github.com/VerifiedMechanisms/autoresearch-runs, branch ar/1dc3df1f7016).
- Lower bound: counting gives W(n) = Omega(2^n/n^2) (Results/CountingLowerBound.lean).
- So the true exponent of n in the denominator lies in [1, 2]. Earlier runs aimed straight
  at exponent 2 and did not get there.

Target. Prove an asymptotic improvement of the exponent: there is a constant delta > 0 with
    W(n) = O(2^n / n^(1+delta))   as n -> infinity,
that is, there are C > 0 and n0 such that W(n) <= C * 2^n / n^(1+delta) for all n >= n0.
Any delta > 0 counts. Do not aim for delta = 1 unless it falls out. Explicit values of C
and n0 are not required, and small n need no separate treatment.

What counts as done, in order of preference:
1. The target, with the final statement in Lean against worstCaseHeadComplexity in the
   eventual form (exists delta > 0, C > 0 and n0 such that the bound holds for all n >= n0,
   or the equivalent IsBigO statement along atTop), with no sorry and no new axioms. If the
   whole proof cannot be formalized in the time, formalize the statement and the new key
   lemma, and give the rest as a complete written proof in TeX with every step explicit.
2. Failing that, a superconstant saving: W(n) = O(2^n / (n * g(n))) as n -> infinity for an
   explicit g tending to infinity (for example log n or log log n).
3. Or the opposite answer: a proof that W(n) >= c * 2^n / n for infinitely many n, which
   shows the exponent 1 is tight.
These do not count: a better constant in front of 2^n/n, bounds for restricted function
classes, certificates for individual truth tables, conditional results resting on an
unproved lemma of comparable strength, and numerical evidence.

Already known to be blocked. Read artifacts/head-compression/mechanism-audit.tex and
scientist-report.tex first, and do not spend time re-deriving these:
- Denominators chosen independently of f cannot work: a fixed list of H denominators that

- Representing the truth table exactly as real values costs about 2^n/(2n) heads by

- One admissible affine ratio with sup norm 1 has correlation at most 2^(1-n) with parity,

- Translating threshold circuits gate by gate fails: the AND of two halfspaces can need

- Reciprocal covers, arithmetic memory decoding, local-cell packing, dominant-term and

- Unchecked claim from an earlier run: O(2^n/n^(1+eps)) heads forces attention weights with

- Numerical searches found exact certificates for single random tables at about
