# Theorems

Read the [definitions](../definitions/README.md) first, then follow the chapters in order:

1. [Foundations and normal form](01_foundations_and_normal_form/README.md): representations of attention scores, head-complexity bounds, and exact results for symmetric functions.
2. [Threshold-degree separation analysis](02_tdeg_separation_analysis/README.md): a counterexample showing that threshold degree does not determine head complexity.

Each chapter's contents page gives its reading order. Each theorem has its own file with a statement, proof, and dependencies on definitions and earlier theorems.

See the [theorem index](../theorems.md) for the complete list of results and their dependencies.
