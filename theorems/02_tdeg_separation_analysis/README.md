# Chapter 2. Threshold-degree separation analysis

This chapter gives a ten-bit function whose head complexity is strictly greater than its threshold degree. Read the [separation example](../../definitions/22_separation_example.md) and [mixed antipodal difference](../../definitions/23_mixed_antipodal_difference.md) definitions first.

| Number | Theorem | Content |
|---|---|---|
| 2.1 | [Threshold degree of the separation example](01_threshold_degree_of_the_separation_example.md) | Prove that the defining quadratic never vanishes and that the threshold degree is exactly two. |
| 2.2 | [Mixed-rank bound for two affine products](02_mixed_rank_bound_for_two_affine_products.md) | Bound the coefficient-matrix rank of mixed antipodal differences by four. |
| 2.3 | [Strict threshold-degree separation](03_strict_threshold_degree_separation.md) | Use the target signs to force rank five, rule out two heads, and compare with two-bit parity. |

Theorem 2.1 uses the affine checkerboard obstruction from Theorem 1.8. Theorem 2.2 uses only definitions. Theorem 2.3 combines both with the threshold-degree head bound and two-head denominator clearing from Theorems 1.12–1.13; the parity comparison uses Theorem 1.20.

The rank expansion stays inside Theorem 2.2. The diagonal-dominance argument and its elementary nonsingularity proof stay inside Theorem 2.3.
