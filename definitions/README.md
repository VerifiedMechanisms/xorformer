# Definitions

Read these definitions in order. Each file is the authoritative location for its notation and conventions.

1. [Model](01_model.md): inputs, embeddings, attention, and the query residual.
2. [Score](02_score.md): scalar scores and exact realization.
3. [Classification](03_classification.md): the threshold convention.
4. [Computability](04_computability.md): computing a Boolean function with a specified number of heads.
5. [Head complexity](05_head_complexity.md): the minimum head count.
6. [Atoms](06_atoms.md): the scalar expressions used in the normal form.
7. [Admissible ratios](07_admissible_ratios.md): the allowed affine coefficient tuples.
8. [Ratio complexity](08_ratio_complexity.md): the minimum admissible ratio count.
