\paragraph{A new paired-offset mechanism under investigation.}
For paired poles $x_s,x_s+\gamma$ and residues $+\kappa,-\kappa$,
the two row states $(D,+\kappa)$ and $(D+\gamma,-\kappa)$ have
identical paired-output differences $2\kappa/(D-x_s)$, for every
$D$ to the right of the pool. Thus a single nonquadratic token pool
can have infinitely many distinct invariant two-state query pairs.
Adding a lower-level numerator background $A_s$ gives the exact
two-row sums
\[
 \frac{2A_s}{D-x_s}\quad(\theta_s=0),\qquad
 \frac{A_s}{D-x_s-\gamma}+\frac{A_s}{D-x_s+\gamma}
       \quad(\theta_s=1).
\]
Their difference is
\[
 \frac{2A_s\gamma^2}{(D-x_s)((D-x_s)^2-\gamma^2)}.
\]
The open issue is coexistence across unboundedly many levels with one
joint pool and the required head budget. Finite exact feasibility
tests do not settle that issue.

\paragraph{Independent audit of the other run.}
The branch \texttt{ar/0f08fe6fb98a} was fetched read-only from the
same origin at \texttt{ad4b30e10e5a} on 24 November. No merge was
performed. Its latest relevant files include
\texttt{continuation-compact-decoder-audit.tex},
\texttt{continuation-equality-cover.tex}, and
\texttt{continuation-global.tex}.

Its universal matching array has $2M$ slots and alphabet size
$q\leq M/(5\log M)$. Hall's theorem plus the stated union bound
provides simultaneous matching for every request vector. For
$r=M\log_2q$, the equality kernel
\[
 K_t(X,Y)=\frac{tX}{tX+Y}-\frac X{X+Y}
\]
then gives a complete written $O(r/\log r)$ promised-grid compiler
with positive orientation. The exact axis subtraction is also written.
The global reverse-orientation transfer remains open. Adding an exterior
penalty $L$ changes the sign factor to
$(Y-\varepsilon)(tX^2-(\varepsilon+L)(Y+L))$, which becomes negative
for large $L$. Nonnegativity before suppression does not fill the gap.

The other run also proves a written exact-flow limitation allowing
arbitrary slot-dependent $K$-term reciprocal functions with one fixed
token library. If each query is an exact nonconstant affine function
of its one switch and independent of every other switch, a stage
block has at most $3K(2K+1)$ independently decoded switches. Its
proof fixes two input slots and routes them to each switch; exact
independence makes their paired-output difference matrix diagonal.
Clearing denominators bounds its rank by $3L(L+1)/2$, $L=2K$.
The resulting whole-butterfly budget is $O(H\log(K+1))$ switches
against $HK$ heads. The exact-value independence and fixed-library
hypotheses are essential. Neither the adaptive Haar family nor the
new target-dependent paired-offset family satisfies them.

\paragraph{Additional scoped audits on this branch.}
\texttt{cd53cc8} proves in writing that fixed generic query offsets
with every maximal baseline row minor nonzero give exactly the same
strict sign family on every sufficiently compact pole-permutation
branch. This was independently audited using Gordan's alternative
and circuit cofactor signs. Singular or scale-dependent offsets are
not covered. \texttt{e0a5218} gives a three-head strict-sign failure
along one specified radial denominator contraction;
\texttt{12f82d4} gives a successful three-head coalescence for the
same target along different directions. Thus the radial example
cannot be promoted to a global compactness obstruction.
