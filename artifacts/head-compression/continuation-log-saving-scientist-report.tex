\paragraph{New construction.}
For $q=2^k$, put $q^2$ memory points in the finite affine plane
$\mathbb F_q^2$. A real token at each point and column encodes $k$ arbitrary
output bits. An exact Cauchy interpolant reads each bit from that token.
The sums of the token kernels on the $q^2$ nonvertical lines have a displayed
rank factorization, which costs $q^2+1$ reverse heads. Distinct points with
different first coordinates share exactly one nonvertical line. This identity
allows one affine-ratio head per point to cancel all its off-target
contributions. The resulting $2q^2+1$ heads realize every sign table with at
most $kq^2$ rows, independently of its number of columns. Grid values are
exactly $+1$ or $-1$.

\paragraph{Admissibility and global transfer.}
The correction denominator is
\[
 1-\sum_i(1-D_{i,g})u_i-\sum_jt_{g,j}v_j,
 \quad 1-\epsilon<D_{i,g}<1,\quad 0<t_{g,j}<\epsilon,
 \quad \epsilon=\frac1{4(r+s+1)}.
\]
It exceeds $3/4$ on the entire Boolean cube and every slope is negative.
The rank heads are also positive on the whole cube; an exact weight-two
gauge makes their slopes strictly negative without altering any grid value.
The existing checked axis repair costs $3H+3$ heads. The checked downward
product-cover assembly then yields
\[
 W(a+b)\le484\frac{2^{a+b}(3H+3)}{ab}+2^a+2^b.

Choosing the least $k$ with $a\le k4^k$ gives $H=O(a/\log a)$.
Balanced blocks finish the claimed logarithmic bound. Integer rounding,
exceptional faces, positivity, and strict output signs are all included in
the Lean proof.

\paragraph{Routes that did not resolve the target.}
Fixed-denominator universality, bounded atoms, saturated priority lists,
isolated token readers, low-order jet constructions, and direct neural
network memory transfers did not supply the universal saving.
Forward equality-cover compilers were confined to their one-hot grid
because their global orientation transfer was missing.
Finite Cauchy and reflection examples supplied only constant improvements.
The successful construction uses shared line aggregates and exact
off-target cancellation, rather than assuming that an isolated bit decoder
or a large VC dimension transfers to this cube.
