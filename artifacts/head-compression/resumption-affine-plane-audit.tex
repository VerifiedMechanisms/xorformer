\paragraph{Encoding and interpolation.}
For $q=2^k$, $k\geq1$, a field $F$ of order $q$ exists. Its underlying set
is in bijection with the $k$-bit words. An injection of the requested
$r\leq kq^2$ rows into $F^2\times\{1,\ldots,k\}$ lets us extend a table
arbitrarily on unused row labels. At each point $g$ and column $j$, one
field element therefore stores exactly the requested $k$ bits.
This argument uses only finite cardinalities; it does not require the
field arithmetic to agree with binary word operations.

Choose distinct real $d_a\in(1-\delta,1)$ and
$t_z\in(0,\delta)$, with $(r+s)\delta<1$ and $\delta<1/2$.
The Cauchy evaluation matrix $1/(d_a-t_z)$ is nonsingular: clearing its
common denominator gives a polynomial of degree at most $q-1$ with $q$
distinct roots, and evaluating the zero polynomial at each $d_a$
annihilates its corresponding coefficient. Consequently each bit vector
has exact reciprocal interpolation coefficients $\eta_{b,a}$.
The Lean proof permits an additional constant $c_b$. This causes no gap:
the rank-grid compiler explicitly supports arbitrary row biases, so the
term $c_b$ is carried without an additional factor per bit.

\paragraph{The essential cancellation.}
For $h=(x_h,y_h)$, use the $q$ nonvertical lines
$L_{a,y_h-ax_h}$. If $g\ne h$ has $x_g=x_h$, no such line contains $g$.
Otherwise exactly one does, of slope
$a(h,g)=(y_g-y_h)/(x_g-x_h)$. Therefore, with
\[
 Z_{a,c,j}=\sum_{g\in L_{a,c}}\frac1{d_a-t_{g,j}},
\]
we obtain
\[
 \sum_a\eta_{b,a}Z_{a,y_h-ax_h,j}
 =\sum_a\frac{\eta_{b,a}}{d_a-t_{h,j}}
  +\sum_{g:x_g\ne x_h}
       \frac{\eta_{b,a(h,g)}}{d_{a(h,g)}-t_{g,j}}.
\]
The first term decodes the requested bit. The left side is a displayed
rank-$q^2$ factorization, and the second term is cancelled by $q^2$
heads, one per point. Each correction head has row-dependent numerator
coefficient $-\eta_{b,a(h,g)}$ and row-dependent pole
$d_{a(h,g)}$, with zero numerator for the excluded rows. These are
arbitrary permitted affine coefficients. The data-column token
$t_{g,j}$ depends on $g,j$ but not on the query row, exactly as required
for one correction denominator.

The line values $Z$ are precomputed real parameters after the whole table
is specified. Computing them does not require an input-dependent product
or an extra attention layer. This is why earlier fixed-pool or
single-token decoder obstructions do not apply.

\paragraph{Actual head budget and whole-cube positivity.}
For any rank factor $f_i g_j$, let
\[
 C=1+\sum_i|f_i|,\quad u_i=C+f_i>0,\quad M=4(r+1)C.
\]
The affine ratio with column numerator $M g_j$, row denominator slopes
$-u_i/(M+u_i)$, and denominator intercept one has grid value
$(M+C+f_i)g_j$. Its full-cube minimum is greater than $1/2$.
One shared affine head removes all column-only terms, so the line rank
factorization costs $q^2+1$ heads, irrespective of coefficient magnitudes.
Each correction denominator has the form
\[
 1-\sum_i(1-D_{i,g})z_i-\sum_jt_{g,j}w_j,
\]
and its whole-cube minimum exceeds $1-(r+s)\delta>0$.
Thus the raw budget is exactly $2q^2+1$.

For a weak denominator with positive minimum $m$, replace it by
$D+\epsilon(2-\sum x_i)$ with $\epsilon=m/(r+s+1)$.
All slopes become strictly negative, the minimum remains positive, and
all weight-two grid values remain unchanged. The already checked
threefold axis repair then gives $6q^2+6$ strict heads and exact zero on
both Boolean axes. Numerators remain affine throughout. The input
coordinates are the original $r+s$ bits.
